# Quant Retrospective

## Overview

Close the run by extracting durable lessons and deciding whether long-term rules changed.

## Inputs

- `status.md`
- `execution-log.md`
- `code-review.md`
- `测试报告.md`
- `changelog.md`

## Outputs

- `insights.md`
- any required updates to `core.md`
- any required updates to controller `AGENTS.md` and repo `AGENTS.md`

## What To Capture

- workflow friction
- testing hazards
- recurring failure modes
- new project knowledge worth preserving
- doc or AGENTS rules that should become durable

## Rule

Do not finish the run until durable rule changes have been reflected in the appropriate long-term file.
