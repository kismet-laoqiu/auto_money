# 支撑与阻力

## 这是什么

Support / Resistance 可以理解成“市场在某些价格区域反复表现出买入或卖出意愿”。支撑像地板，阻力像天花板，但更准确的说法不是“一条线”，而是“一个区域”。

对金融小白最重要的理解是：它不是玄学，而是市场参与者集体行为留下的痕迹。某个价格附近如果反复出现买盘、防守、止跌、回弹，那它就更像支撑；反过来，如果反复出现卖压、冲高回落、上不去，那它就更像阻力。

## 为什么有人用

1. 它直观，几乎所有交易者都能看懂。
2. 它适合做 entry、stop、target 的位置层设计。
3. 它既能给人看，也能转成机器特征。
4. 它经常和 round number、趋势线、Fib、价格行为形成共振。

## 什么时候容易有效

1. 市场流动性足够好，历史成交密集。
2. 一个区域被多次测试，但没有被有效突破。
3. 趋势没有发生根本 regime shift。
4. 你把它当 zone，而不是精确点位。

## 什么时候最容易失灵

1. 强趋势加速时，阻力会被一脚踢穿，支撑也会直接失效。
2. 财报、宏观数据、政策冲击会让旧价位突然失去意义。
3. 你只看“到价”，不看碰到这个区域后的反应。
4. 你把几十年前的旧高低点硬拿来解释今天的交易。

## 用真实历史数据举例

### 例子 1：ETHUSDT，最近样本里的 3058 一带

我们在 ETH 日线近 260 根 bar 的 pivot clustering 里，发现约 3058.52 附近出现了 5 次 high/low 聚集。这种“同一区域反复被市场记住”的现象，就是把抽象的支撑阻力变成机器特征的最好入口。

对小白来说，重点不是记住 3058 这个数字，而是理解：如果很多次高低点都围着一个区域出现，这个区域往往比随机价格更值得观察。

### 例子 2：XAUUSD，3261 一带的低点聚集

XAUUSD 最近样本里，约 3261.37 一带出现了 5 次 low cluster。这类低点群经常适合拿来讲“支撑不是一根线，而是一片会反复吸引买盘的区域”。

黄金特别适合做这个教学，因为它本身很容易围绕关键整数位和宏观预期反复震荡，区域感比单点感更强。

### 例子 3：BTCUSDT，107000 附近的反复碰撞

BTC 最近样本里，约 107019.78 附近也出现了多次 high/low cluster。这类区域不是稳定得像铁板，但它足以说明高波动品种同样会留下“市场反复记住的价位”。

## 如何转成机器规则

1. 用 pivot detection 找局部高低点。
2. 把相近价格按 tolerance 聚类，而不是当作完全不同的点。
3. 计算每个 cluster 的 touch count、最近一次触碰时间、平均反应幅度。
4. 区分“只是碰到”与“碰到后发生 reversal”。
5. 把 breakout 也量化，例如收盘是否真正站上区域上边界、是否伴随放量。

## 如何避免过拟合

1. 只要价格接近就算命中，这会制造很多假阳性，所以必须设 band 和确认条件。
2. 不要把 cluster 宽度调到刚好适配历史最佳结果。
3. 不能只看 bounce，不看 breakout，否则会把趋势市场误判成震荡市场。
4. 必须跨 crypto、stock、gold 三类 bucket 检验。
5. 必须和交易成本一起看，因为很多 bounce edge 很小。

## 术语表

- `support`：更像买盘防守区的价格区域。
- `resistance`：更像卖压上限区的价格区域。
- `cluster`：多个相近 pivot 聚在一起形成的区带。
- `bounce`：价格碰到区域后反向离开。
- `breakout`：价格有效穿过原有区域边界。
