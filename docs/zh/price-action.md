# 价格行为学

## 这是什么

Price Action 可以翻成“价格行为”，本质上就是只看价格本身怎么走，而不是先叠一堆指标再去解释价格。它关心的是 K 线实体、影线、收盘位置、突破、回踩、加速、衰竭，以及这些行为发生在什么位置。

如果你是金融小白，可以把它理解成一句话：同样是一根阳线，出现在趋势中段、关键支撑位、还是涨完一大段之后，意义完全不同。Price Action 不是“背蜡烛图名字”，而是“价格在这个位置做了什么”。

## 为什么有人用

1. 它直接、可视化，不需要先理解复杂指标公式。
2. 它天然能和支撑阻力、趋势、波动率结合。
3. 它非常适合做 trigger，也就是“什么时候执行”这一层。
4. 它的失败也很直接，一旦形态无效，很容易定义止损。

## 什么时候容易有效

1. 市场有比较清晰的趋势或 clear range。
2. 关键价位附近成交足够活跃，价格反应不是随机抖动。
3. 你把形态放在上下文里看，而不是孤立看一根 K 线。
4. 你的执行成本不高，否则很多小 edge 会被吃掉。

## 什么时候最容易失灵

1. 只看形态名字，不看位置和趋势。
2. 低 timeframe 噪音过高，长得像信号但没有后续。
3. 高冲击事件前后，单根 K 线会被消息主导。
4. 交易成本、滑点、点差一加进去，纸面 edge 消失。

## 用真实历史数据举例

### 例子 1：BTCUSDT，2024-02-24 的 bullish engulfing

我们在 BTC 日线里扫到了一个很强的 bullish engulfing 样本：

- 触发日：2024-02-24
- 当日收盘：51568.22
- 后续 5 个交易日收益：+18.54%

这个例子适合拿来讲“形态要配上下文”。如果你只说“出现吞没形态就买”，那是幼稚规则；更合理的解释是：前一根是弱，后一根把前一根实体包住，说明短期 control 从卖方切回买方，且后面确实出现了跟随。

### 例子 2：ETHUSDT，2024-03-14 的 bearish engulfing

ETH 日线里有一个反面方向的样本：

- 触发日：2024-03-14
- 当日收盘：3881.70
- 后续 5 个交易日收益：-18.63%

这个例子能帮助你理解 bearish trigger：不是因为“K 线长得黑”就空，而是因为价格在高位附近出现了由强转弱的行为，并且之后真的跟出了明显下跌。

### 例子 3：CRCL，2025-07-18 的 bearish engulfing

CRCL 是高波动美股样本，特别适合提醒你不要把 crypto 的经验硬套过来：

- 触发日：2025-07-18
- 当日收盘：223.78
- 后续 5 个交易日收益：-13.82%

这个例子告诉你，Price Action 在高波动单票上经常更“暴力”，信号成立时 move 很快，但假突破和滑点也会更重。

## 如何转成机器规则

最稳的做法，是把形态拆成可测量的 bar features：

1. 实体大小 / 全日振幅。
2. 上影线、下影线占比。
3. 收盘在当日区间中的位置。
4. 是否发生 engulfing、pin bar、inside bar、outside bar。
5. 形态发生前的趋势方向、波动率、距离最近 key level 的百分比。
6. 触发后 1、3、5、10 根 bar 的 follow-through。

这样你得到的是 feature layer，而不是迷信“某某形态一定涨”。

## 如何避免过拟合

1. 不要同时优化几十种 candle name。
2. 不要把 trend 定义写得模糊，例如“看起来在涨”。
3. 必须把手续费、滑点、隔夜风险算进去。
4. 同一个形态要跨 BTC、ETH、CRCL、XAU 看，而不是只挑成功图。
5. 如果某个形态只在单一市场、单一时期有效，就把它当局部现象，不当普适规律。

## 术语表

- `engulfing`：后一根实体把前一根实体包住。
- `pin bar`：影线很长、实体较小的一根 K 线。
- `follow-through`：信号出现后，价格有没有继续朝预期方向走。
- `trigger`：真正执行交易的触发条件。
- `context`：形态发生的背景，包括趋势、位置、波动率。
