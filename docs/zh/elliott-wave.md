# 艾略特波浪理论

## 这是什么

艾略特波浪理论的核心想法很简单：价格并不是完全随机乱走，它经常会以“推进一段，再修正一段”的方式前进。最常见的教学版本，是把顺趋势阶段看成五段 impulsive move，把逆趋势修正看成三段 corrective move。

对金融小白来说，可以先把它理解成一种“给走势分段”的语言，而不是一套神秘预测术。它最有价值的地方，不是告诉你市场一定会怎么走，而是逼你回答三个问题：现在是推进段，还是修正段？这段上涨/下跌有没有结构？如果我看错，哪里算 invalidation？

## 为什么有人用

第一，它能把“看着像在涨”这种模糊感觉，压缩成更具体的结构描述。第二，它天然适合和回撤、撑压位、趋势交易结合，因为波浪理论并不只看方向，也看回撤深度和节奏。第三，它很适合做风险管理，因为一旦你给出一个波段假设，就能同时给出“如果这不是第 2 浪而是趋势反转，我应该在哪儿认错”。

## 什么时候容易有效

1. 市场本身在走趋势，而不是横着磨。
2. 标的流动性足够好，价格 swing 比较清楚。
3. 你看的不是太低的 timeframe，噪音没有把结构完全打碎。
4. 你不是单独使用波浪，而是把它和 pivot、Fib、support/resistance 合在一起。

## 什么时候最容易失灵

1. 横盘震荡时，几乎任何一段都能被“硬数成波浪”。
2. 大新闻冲击、财报跳空、宏观数据突发时，结构会被直接打断。
3. 不同分析师在同一张图上给出不同 wave count，这是它最著名的问题。
4. 如果你先有结论，再回头“补数浪”，它会变成一种自我证明工具。

## 用真实历史数据举例

### 例子 1：BTCUSDT，2025-07-02 到 2025-07-15

我们在日线 pivot 扫描里找到一段很典型的 wave-like sequence：

- 2025-07-02：105100.19
- 2025-07-05 左右的高点：110529.18
- 2025-07-08 左右的回撤：107429.57
- 2025-07-10 左右的再推进：123218.00
- 2025-07-15 左右的回撤：115736.92

这段并不等于“ textbook 标准五浪”，但它很适合教学：你能直观看到 higher high 和 higher low 在延续，说明市场至少在这一小段里更像推进，而不是纯震荡。真正实用的做法，不是坚持说“这一定是第 1-2-3-4-5 浪”，而是把它翻成机器能懂的条件：higher highs、higher lows、回撤不破关键前低、回撤比例没有过深。

### 例子 2：ETHUSDT，2025-04-30 到 2025-05-18

ETH 日线里也有一段很适合讲波浪结构的序列：

- 2025-04-30：1731.70
- 2025-05-02 附近高点：1873.17
- 2025-05-06 附近回撤：1752.00
- 2025-05-10 附近延伸：2738.50
- 2025-05-18 附近回撤：2323.21

这里最重要的观察不是“数得漂不漂亮”，而是第二次推进明显强于第一次，说明市场在那一段有 acceleration。这类 acceleration 在波浪语言里经常被拿来描述“强势推进段”，但机器化时更稳的写法是：第二次上涨幅度 / 第一次上涨幅度、上涨时 ATR 扩张、回撤未破前一 swing low。

## 如何转成机器规则

不要把“第 3 浪通常最长”直接写成交易规则。更稳的做法是把理论拆成 feature：

1. 用固定 pivot window 找 swing highs 和 swing lows。
2. 计算连续 swing 是否满足 higher-high / higher-low 或 lower-low / lower-high。
3. 计算每段推进幅度和回撤幅度。
4. 计算回撤相对前一推进的比例，观察是否落在 38.2% 到 61.8% 一类的常见区间。
5. 给每条结构打分，而不是直接输出 buy/sell。

这样做的好处是：理论先变成结构信息，策略层再决定这些结构信息值不值得交易。

## 如何避免过拟合

1. 不要手工重标 wave count。机器规则必须 deterministic。
2. 不要为每个标的单独发明一套“专属浪型”。
3. 不要要求图形完美对称。现实市场很少长成教科书插图。
4. 必须跨资产验证：BTC 有效，不等于 ETH、CRCL、XAU 也有效。
5. 一定要把失败样本留在文档里。波浪理论最容易被事后解释污染。

## 术语表

- `pivot`：局部高点或低点。
- `impulsive move`：更偏顺趋势推进的一段。
- `corrective move`：更偏逆趋势修正的一段。
- `wave count`：你如何给一段走势分浪。
- `invalidation`：如果价格走到这里，原假设应当作废。
